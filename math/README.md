# 數學口算抽考（康軒、南一、翰林版 一到六年級）

網頁：<https://tawaki.github.io/school/math/>

手機拿在家長手上：選版本、年級、學期和單元（可多選），家長念題目，孩子用心算口頭回答，家長按「答對」或「答錯」。

- **口說題**：計算、單位換算、文字題等，孩子不用看螢幕。答案可以直接顯示給家長看，也可以先蓋住。
- **看圖題**：時鐘、錢幣、分數圖、角、三角形、四邊形、尺、數線、長條圖、折線圖、圓形圖、統計表、月曆、方格面積、積木體積。要讓孩子看螢幕，答案一定先蓋住，家長點一下才顯示。
- 比長短、容量、重量的比較、線對稱這類要動手操作的單元不出題，單元上會標示。
- 按錯了可以「回上一題重新判定」；題目不適合可以「這題不算，換一題」。
- 結束後列出每題對錯和花的秒數；答對但想得特別久的題目，秒數會標成紅色。
- 答錯的題目記在這台裝置的瀏覽器裡（常錯題），之後答對會慢慢移除。不會上傳到任何地方。
- 網址 `?p=南一&v=3下&u=3,7` 可以直接指定版本、年級學期和單元。

## 檔案
- `index.html`：網頁。
- `skills.js`：題目產生器（每種題型一個 `def(...)`），題目都是隨機產生，沒有題庫。
- `units.json`：各版本、各冊的單元，以及每個單元要出哪些題型（由 `build_units.py` 產生）。

## 資料來源
單元與小節名稱取自均一教育平台「課程對照」的類康軒、類南一、類翰林版 <https://www.junyiacademy.org/course-compare/>，
不是課本原件，可能和最新版課本的單元順序或名稱略有不同。

## 重建資料
```
python3 src/fetch_units.py   # 抓 18 個頁面（3 版本 × 6 年級）-> src/units_raw.json
python3 build_units.py       # 依小節名稱對應題型 -> units.json；沒對到的小節列在 src/unmatched.txt
```
